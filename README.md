# Go Before You Forget
Turn your endless list of saved places into places you'll actually visit. Because saving a place isn't the same as remembering it.
## 🤔 The Problem
Like many people, I save **a lot** of places.

☕ Coffee shops
🥐 Bakeries
🌳 Parks
🍜 Restaurants

I tried using Google Maps, but after a while all I had was an endless map full of pins.

I tried manually adding places to a Notion/Notes list, but after three places I gave up — it simply took too much time.

I even tried sending Google Maps links to a chat with myself. The result? An endless conversation full of links that I never opened again.

I needed something that was:

- ⚡ Fast
- 😊 Easy to use
- 📱 Mobile-friendly
- 💡 Actually helpful

Something that wouldn't just save places, but would also help me **remember why I saved them** and, most importantly, **actually visit them someday**.

## ✨ The Solution

Go Before You Forget automatically turns saved places into a structured Notion database.

Instead of an endless Google Maps list, every place becomes searchable, organized, and ready for future automations and AI-powered recommendations.
- 📍 Name
- 🏷️ Category
- ⭐ Rating
- 📝 Personal notes
- 📅 Date added
- 📌 Status
- AI summary

---

## 🎯 Why Not Just Google Maps?

Google Maps is great for discovering places.

Go Before You Forget is about **remembering** them.

Instead of collecting hundreds of forgotten pins, you build a personal database that grows with you.

## 📱 How It Works

choose a place you want to save in Google Maps
-> 
click Share
->
Apple Shortcut ask to add a personal note if you'd like
->
Notion API
->
Personal Places Database filled out automatically with Google API and Gemini API

## ❤️ Why I Built This

I built Go Before You Forget because I realized I had hundreds of places saved across Google Maps — but I almost never visited them or forgot why I saved them.

I wanted something that helps me rediscover places I had already chosen myself.

This project is the first step toward building a collection of personal tools that help me explore my city more intentionally.
